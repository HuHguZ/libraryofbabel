Цифровое воплощение легендарной Вавилонской библиотеки из одноимённого рассказа Борхеса. Библиотека содержит **все возможные книги** &mdash; каждую комбинацию символов, которую только можно составить. Каждая страница, которую вы когда-либо прочтёте или напишете, уже существует здесь. Каждое слово, каждая мысль, каждая история &mdash; записаны и ждут, когда их найдут.

## Устройство библиотеки

Библиотека устроена так же, как описал её Борхес:

```
                ┌─────────────────────┐
                │   Шестигранная       │
                │     галерея          │
                │                     │
                │  ╔═══╗   ╔═══╗      │
                │  ║ 5 ║   ║   ║      │
                │  ║   ║   ║   ║      │
                │  ║стен║   ║   ║      │
                │  ╚═══╝   ╚═══╝      │
                │                     │
                └─────────────────────┘

       стена        полка        том        страница
     ┌───────┐   ┌───────┐   ┌───────┐   ┌──────────┐
     │ 1 — 5 │ → │ 1 — 7 │ → │ 1 — 31│ → │ 1 — 421  │
     └───────┘   └───────┘   └───────┘   └──────────┘

       Каждая страница: 4 819 символов
```

## Возможности

**Поиск текста** &mdash; введите любой текст, и библиотека найдёт страницу, на которой он записан. Ваш текст уже существует &mdash; нужно лишь знать, где искать.

**Точный поиск** &mdash; найдите страницу, целиком заполненную вашим текстом, без посторонних символов.

**Поиск по заголовку** &mdash; каждый том имеет название. Найдите книгу по её заголовку.

**Обзор библиотеки** &mdash; выберите координаты вручную: стену, полку, том и страницу &mdash; и загляните в случайную книгу на пересечении этих координат.

**Случайная страница** &mdash; позвольте библиотеке самой выбрать для вас страницу из бесконечности.

**3D-галерея** &mdash; войдите в шестигранник, пройдитесь вдоль полок, снимите том и откройте страницу.

## Запуск

```bash
# установка зависимостей
npm install

# режим разработки
npm run dev

# сборка для продакшена
npm run build && npm start
```

Приложение будет доступно по адресу `http://localhost:3000`.

## 3D-галерея

Маршрут `/explore` — это прогулка по Библиотеке от первого лица, устроенной так, как её описал Борхес:

- **шестигранная галерея** с пятью стенами полок и вентиляционной шахтой посередине; за низкими перилами видны галереи выше и ниже;
- **две лампы** — «сферические плоды», дающие скудный, но неугасимый свет;
- **вестибюль** за шестой стеной: зеркало, два чулана и **винтовая лестница**, по которой можно подниматься и спускаться сколько угодно — на каждом этаже свои две галереи;
- **бесконечный мир**: две галереи делят один вестибюль, пары повторяются по этажам, и всё, что рядом (за дверью, этажом выше и ниже), уже загружено и отрисовано со своими собственными материалами — переход не перерисовывает сцену. Дальние этажи подгружаются по мере движения, а адреса галерей выводятся детерминированно из стартового, так что дорога назад ведёт к тем же книгам;
- **полка крупным планом** с заглавиями на корешках (выбранная полка освещена), **раскрытый том** с указателем всех 421 страниц и **читалка** — трёхмерная книга с перелистыванием, поиском по странице и подсветкой найденного.

Управление: щелчок по сцене отдаёт мышь взгляду, как в шутере — прицел посередине, клик открывает то, что под ним, `Esc` возвращает курсор. Где браузер разрешает захват курсора (pointer lock), используется он; где нет (встроенные панели предпросмотра, песочницы) — курсор прячется, взгляд ведёт свободная мышь, а у краёв экрана поворот продолжается сам. `W A S D` — идти, `Shift` — бежать, пробел — прыгнуть, колесо — приблизить. До первого щелчка работает перетаскивание; на телефоне — палец и два пальца. Каждая галерея получает свой облик от собственного адреса: пол, стены, потолок, дерево полок, выделка кожи и палитра переплётов выбираются детерминированно из сгенерированных текстур (`public/textures`, сделаны локально в ComfyUI моделью Z-Image Turbo).

Поиск понимает только алфавит Библиотеки — 33 строчные русские буквы, пробел, запятую и точку; всё остальное отбрасывается, а строка поиска показывает, что именно будет искаться.

## Философия

> Когда было провозглашено, что Библиотека объемлет все книги, первым ощущением была безудержная радость. Все люди почувствовали себя обладателями нетронутого тайного сокровища. Не было проблемы &mdash; личной или мировой, &mdash; для которой не существовало бы красноречивого решения в какой-нибудь из шестигранных галерей.

Этот проект &mdash; попытка прикоснуться к бесконечности через конечный экран. Каждый адрес &mdash; это уникальная точка в пространстве всех возможных текстов. Библиотека не генерирует текст &mdash; она *находит* его. Страницы не создаются &mdash; они всегда существовали.
